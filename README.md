## ✨ Características
- 💳 **Gestión de cuentas** múltiples (Banco, Efectivo, Tarjeta, Ahorro)
- 📊 **Gráficos interactivos** con Chart.js
- 🎨 **Personalización de colores** para cada cuenta
- 📱 **Diseño responsive** (móvil y desktop)
- 💾 **Almacenamiento local** - Tus datos se guardan en tu navegador
- 🌓 **Interfaz moderna** y minimalista
- 📅 **Seguimiento por fechas** de todos los movimientos
- 🏷️ **Categorías personalizables** (Comida, Transporte, Vivienda, etc.)
-  **Presupuestos** por categoría
